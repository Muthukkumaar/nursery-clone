Greenden is a modern, fully responsive multi-page website built using HTML and Tailwind CSS. It is designed to introduce students and developers to real-world layout practices, utility-first CSS styling, and responsive web design.

Website Link: 

🚀 Features
Responsive Layout: Adapts seamlessly to all screen sizes (mobile phones, tablets, and desktop monitors) using Tailwind's responsive modifiers (sm:, md:, lg:).

Multi-Page Structure: Includes three key sections/pages:

Home Page: Welcoming hero section, feature highlights ("Why Choose Us"), and a curated best-sellers showcase.

Products Page: Plant product collection featuring grid layouts, category filters, and interactive elements.

Contact Page: Clean contact details and an interactive user feedback form.

Utility-First Styling: Utilizes Tailwind CSS flexbox, grid, spacing, and typography utilities for a clean and professional finish.

📚 Learning Objectives
Learn how to structure a responsive multi-page website using Tailwind CSS.

Gain hands-on experience with CSS Flexbox, Grid, spacing, and text utilities.

Write clean, maintainable, and scalable HTML and utility classes.

Build confidence in creating aesthetic, accessible, and user-friendly interfaces.

🛠️ Tech Stack
HTML5 – Markup structure

Tailwind CSS – Styling and responsive design

🎯 Outcome
By completing the Greenden project, you get a polished, professional plant store web project to showcase in your portfolio, demonstrating strong fundamentals in modern CSS frameworks and responsive web design.
